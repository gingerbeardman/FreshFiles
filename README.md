# Fresh Files

Fresh Files is an extension for the [Nova editor](https://nova.app).

An alternative file browser sidebar that shows only recently modified files, using Git history to reduce cognitive load when navigating large projects.

See the internal [README](/Fresh%20Files.novaextension/README.md) for more info.

## Inspired by

[Fresh File Explorer](https://github.com/FreHu/vscode-fresh-file-explorer) for VS Code.
